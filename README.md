If you're interested in this file, odds are you are either interested in hiring me, or you already know how to play with Bash 
scripts. Possibly both. Still, might as well cover my bases, no?
(Btw this just ain't gonna work on Windows or Mac unless you're going through the effort to set up Bash for them. 
If you know how to do that, you don't need these instructions for sure.)

Step 1: Don't move anything. All these files need to be at the same level.
Step 2: You need to make TextTacToe executable.
  2a: Right click on the TicTacTerminal folder in your file browser and select "Open in Terminal".
  2b: Type exactly as follows, then hit enter: chmod 771 TextTacToe
Step 3: Now, in the same terminal window, type ./TextTacToe and hit enter. The ./ is very important.
Step 4: Enjoy!
